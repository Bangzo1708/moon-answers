The Moon finally answers back: one line (132 characters) in the voice of a weary, four-billion-year-old Moon who has heard every wish ever made on it — and never once been wished a night off. Chosen from three hand-written candidates for the strongest single-read laugh and the clearest Moon voice. Writes the chosen line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
